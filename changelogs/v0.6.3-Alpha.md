## News!
- Added optional port support for `/addserver`, so domain-only hosts can be used without requiring an explicit port.
- Added a dedicated auto-reconnect toggle in the settings file, enabled by default for normal behavior.
- Added stricter reconnect handling to prevent duplicate retry loops and duplicate rescheduling.
## Improvements!
- Auto-reconnect now respects the saved settings value instead of always retrying after disconnects.
- Canceling reconnects now checks the actual in-memory reconnect state instead of only the saved last-session file.
- Startup reconnect restoration now skips a saved session when auto-reconnect is disabled.
## Fixes
- Fixed duplicate reconnection attempts caused by overlapping reconnect timers and stale retry events.
- Fixed the false "Automatic reconnection cancelled and last session cleared" message when no reconnect session was active.
- Fixed reconnect attempts continuing after max retry exhaustion when the bot had already given up.
